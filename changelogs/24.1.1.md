# Added

* **Attributions**
    * Added custom attribution fields to data providers which normally have their attributions embedded in the data itself.
    * This can be used to add attributions when they are not specified in the data, but known by the application.
    * Those fields have been added to [single models](reference/HrzProtocol.SingleModelLayer), [3D Tiles](reference/HrzProtocol.ThreeDTilesLayer), [TileJSON vectors](reference/HrzProtocol.TileJsonVectorDataProviderParams), [ArcGIS rasters](reference/HrzProtocol.ArcGisRasterProviderParams), [Cesium terrain tiles](reference/HrzProtocol.CesiumTerrainRasterProviderParams), [TileJSON rasters](reference/HrzProtocol.TileJsonRasterProviderParams), [TMS rasters](reference/HrzProtocol.TmsRasterProviderParams), and [WMS rasters](reference/HrzProtocol.WmsRasterProviderParams).

# Fixed

* Fixed 3D Tiles with a size of zero along one axis but not the other two not being displayed.
* Fixed a GPU memory leak when using 3D Tiles tilesets containing `i3dm` tiles.
* Fixed editable shape control points not clamping to the terrain when a DTM is loaded.
* Fixed the screen going black when the camera would go below the sea level with the atmosphere enabled.
* Fixed impostors culling not accounting for clamping, which could lead to situations where neither model or impostor would be rendered.
* Fixed the lighting of instanced model impostors, making them blend better with their surroundings.
* Flat polygon baking is now faster in some cases where it was unexpectedly slow.
* Suppressed an error message when all features of a tile are culled because of the clip-to-tile configuration setting.
