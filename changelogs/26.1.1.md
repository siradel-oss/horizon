# Changed

* The [Mapbox service](reference/HrzProtocol.MapboxService.md) now applies the `http_headers` of [MapboxTranslationParams]($proto) to every external resource of the translated style: the sprite image, the fonts, and the data of `raster`, `vector` and `geojson` sources. Previously, they were only applied to the sprite index document.

# Fixed

* Fixed the Linux native package shipping the same unoptimized binary without debug information for both release and debug.
* Reduced the yellow tint of the sky near the horizon.
