# Added

* Added support for vector features made of a collection of geometries of different types (e.g. GeoJSON’s `GeometryCollection`).
    * Each representation renders the geometries it supports, and ignores the others.
* **Sun settings**
    * The Sun position in the sky can now be set to a fixed position with regard to the planet in [SunSettings]($proto), either through a date in an idealised year (no leap years) at the prime meridian ([SolarDate]($proto) with `at_prime_meridian` set), an actual date in a time zone ([CalendarDate]($proto)), a Unix timestamp, or an arbitrary angle, measured from anywhere on Earth ([AngularDirection]($proto) with `geographic_position` set).
    * The Sun position can also be fixed with respect to the camera, through the `FRAME_CAMERA` camera frame of [AngularDirection]($proto).
    * The eccentricity of the Earth’s orbit around the Sun is now taken into account when computing the Sun’s position in the sky.
* Added support for the deprecated, yet still in use, `gltfUpAxis` property of 3D Tiles.
* Added the [`GetInfo`](/doc/reference/HrzProtocol.ViewerService.md#method-GetInfo) method to the [ViewerService]($proto). This method can be used to retrieve static information about the viewer instance. Currently it only contains the version.

# Changed

* **Vector tiles**
    * Multi-geometry features are no longer split into multiple features in vector tiles.
    * [FlatOverlayPointVectorRepr]($proto), [HeatmapVectorRepr]($proto), and [ModelVectorRepr]($proto) now render one instance per point, including every point of multi-points and geometry collections.
    * Instanced models are no longer placed on polyline and polygon geometries.
    * [SymbolVectorRepr]($proto) symbols are now placed at the anchor of their feature, for any geometry type.
    * The anchor placement rules have been updated. See the detailed [anchor placement rules](/doc/vector_tile_layers.md#feature-anchors).
    * The [feature type special attribute](/doc/vector_tile_layers.html#feature-type) now has an undefined value for features containing geometries of different types.
    * The `InMemoryVectorFeature` and `ClientFeature` messages have been merged into the [VectorFeature]($proto) message.
    * The `InMemoryVectorFeatureGeometry` and `ClientFeatureGeometry` messages have been merged into the [VectorFeatureGeometry]($proto) message.
    * [VectorFeature]($proto) now contains an array of [VectorFeatureGeometry]($proto), allowing it to represent multi-polygons and geometry collections.

# Removed

* The `SunDirectionMode` enum has been deleted, instead the Sun direction mode is selected through the `direction` `oneof` of [SunSettings]($proto).

# Fixed

* **3D Tiles**
    * Fixed 3D Tiles reloading sometimes getting stuck. This could happen when changing material properties while a reload was still happening.
    * Fixed jittering models for i3dm 3D Tiles with no defined `RTC_CENTER` offset.
    * Fixed support for 3D Tiles whose JSON batch tables do not contain the same number of values as there are features in the tile. Missing values are replaced with a default value.
* **Vector tiles**
    * Fixed [ExtrudedGeometryVectorRepr]($proto) drawing a wall between consecutive linestrings of the same polyline feature.
    * Fixed non-first points in multi-points Geobuf features not being placed at their correct location.
    * Fixed styling random functions not being deterministic between builds when evaluated without feature IDs.
* Fixed NaN values not being detected in data textures on 3D models on recent versions of Chrome.

# Upgrade notes

* **Sun settings**
    * The mode must now be selected by setting a value to the `direction` `oneof` of [SunSettings]($proto) instead of using the `SunDirectionMode` enum.
    * `SUN_DIRECTION_RELATIVE_TO_DATE` has been replaced with [SolarDate]($proto), with `at_prime_meridian` set to `false`.
    * `SUN_DIRECTION_RELATIVE_TO_CARDINAL_FRAME` has been replaced with [AngularDirection]($proto), with `camera_frame` set to `FRAME_ENU`.
    * `SUN_DIRECTION_RELATIVE_TO_TANGENTIAL_FRAME` has been replaced with [AngularDirection]($proto), with `camera_frame` set to `FRAME_CAMERA_HEADING`.
    * `azimuth` is now measured clockwise.
* **Vector data**
    * Replace instances of `InMemoryVectorFeature` and `ClientFeature` with [VectorFeature]($proto).
    * Replace instances of `InMemoryVectorFeatureGeometry` and `ClientFeatureGeometry` with [VectorFeatureGeometry]($proto).
