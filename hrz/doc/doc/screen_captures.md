# Screen captures

Captures of the current view can be taken using the `ScheduleFrameCapture` method of [ViewerService]($proto), and then retrieved using the `frame_capture` message from the [message queue](message_queue.html).

> [!note]
> The engine must be allowed to run normally after scheduling the capture for a result to be eventually returned.
